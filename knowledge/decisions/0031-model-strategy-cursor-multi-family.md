# ADR 0031: Cursor ハーネスのモデル戦略＝クロスファミリー検証

- 状態: 受理（廃止対象: [[0026]]；改正: [[0033]] [[0037]] [[0039]] [[0040]]）
- 改正注記: Grok 世代ピンは [[0040]] で 4.6、[[0049]] で 4.7 high。検証/内省は [[0049]] で Opus 5.5 high。第3は [[0046]] で Muse medium。計画/レビューは [[0047]] で Fable 5.1。決定本文の世代と Opus ゲート列挙は履歴。席骨格（親 Grok・Claude ゲート・3ファミリー）は維持。
- 日付: 2026-07-12
- 背景: 精度は「1席あたりのモデルの大きさ」ではなく「独立した検証の深さ」で決まる。
  Cursor では subagent ごとに別ファミリーを割り当てられる。同一ファミリー N 体の多数決は盲点が相関する。
- 決定:
  - **親チャット = Grok 4.6**（[[0040]]）。Claude ゲートは名前付き Task の `model:` で起動。
  - **実装の並列展開 = Grok 4.6**（[[0040]]。明文化済みタスクのみ）。独立レビューは免除しない。
  - **独立敵対レビュー（全変更）= Claude ゲート・新しい文脈・敵対的**（`adversarial-review`）。
  - **高リスク検証 = 3体・3ファミリー**（Opus 5 / Grok 4.6 / Muse Spark 1.3 medium・[[0046]]）。過半数確認まで前進不可。
    ファミリー多様性は実装席でなくレビューで稼ぐ。
  - **内省 / 前進判定 / 設計 / plan-confirm = Opus 5**。
  - **不変条件**: 同一文脈の自己確認で前進段を満たさない。
  - **ハーネスモデルを対象外 LLM の代役にしない**（[[0039]]）。
  - 内省時にモデル別の失敗モードを learnings に残し、蓄積後に `model-routing.yaml` へ昇格する。
- 結果: `.claude/agents/*.md` の `model:` が宣言的に効く。API 予算の席階層は [[0033]]。

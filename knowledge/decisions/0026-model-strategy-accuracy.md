# ADR 0026: ハーネスのモデル戦略＝精度優先（Fable 頭を廃し独立敵対レビューをゲート化）

- 状態: 廃止（後継 [[0031]] / [[0040]]）（廃止対象: AGENTS.md「モデル戦略（Fable 頭）」）
- 現行注記: 計画確定 / レビューは **Fable 5.1**（[[0047]]）。内省 / 検証は **Opus 5.5**（[[0049]]）。
  親チャットと実装の並列展開は Grok 4.7 high。第3は Muse Spark 1.3 medium（[[0046]]）。
  決定本文の Opus 固定と「Fable を全席から廃止」は廃止時点の履歴。
  Sonnet/Haiku への定型委譲は使わない（[[0031]] / [[0033]] / [[0040]]）。
- 日付: 2026-07-06
- 背景: 開発ハーネス（Claude Code）の頭を **Fable 5** に置いていた（安価に大量オーケストレーション）。
  だが運用は **Max 5 プラン**でコストが制約でなくなり、目的は「出費最小」から**出力の精度担保**に一本化した。
  ここで効く事実: **精度は"1席あたりのモデルの大きさ"ではなく"独立した検証の深さ"で決まる**。
  同一文脈で「書いて→自分で確認」は著者が自分の誤りに盲目で精度が上がらない。
- 決定: **精度優先のモデル戦略に転換**。Fable を全席から廃止。
  - **Claude 席（計画確定 / 内省 / 検証 / レビュー）= Opus 5 固定**（旧 4.8。[[0037]]）。
    親チャット（統合 / ディスパッチ）は Grok 4.6（[[0040]]）。検証は常に独立。
  - **実装**: 高リスク・非自明な論理のゲートは **Opus 5**。並列展開は Grok 4.6。
    Sonnet/Haiku への定型委譲は現行戦略ではない。独立レビューは免除しない。
  - **独立敵対レビュー（全変更のデフォルトゲート）**: **実装とは別の agent 呼び出し・新しい文脈・敵対的
    プロンプト**（「チェックして」ではなく「壊せ／どこが間違っているか探せ」）を Opus 5 で走らせる。
    `security-reviewer` / `verifier` の既定は Opus 5（[[0037]]）。
  - **高リスク検証**: Opus 5 / Grok 4.6 / Muse Spark 1.3 medium の3体多数決（[[0046]]）。過半数確認まで前進不可。
  - **内省（reflector）= Opus 5 固定**。
  - **不変条件**: レビューは**必ず実装と独立した新しい文脈・敵対的**であること。同一文脈の自己確認で
    前進段を満たしたと見なさない。単独敵対レビューを全変更に、3体多数決を高リスクに掛ける（精度/ノイズの均衡）。
- 結果: 頭の推論品質と検証の独立性が上がる。Max プランの余剰を"独立検証の冗長化"に振り向け、
  「Sonnet で安く書いて浮かす」設計を捨てる。将来コストが制約化した時のみ [[0024-autonomy-modes]] と連動した
  モード別頭モデル（自動/長時間=安モデル頭）を再検討する余地は残す。

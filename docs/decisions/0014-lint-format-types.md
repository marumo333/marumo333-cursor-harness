# ADR 0014: 検査 / 整形 / 型

- 状態: 受理（改正: [[0039]] [[0041]]）
- 日付: 2026-07-04
- 背景: 型ゲートを空の `pnpm run check` で偽装しない。パッケージマネージャは pnpm（[[0041]]）。
- 決定:
  - ハーネス scripts はモジュール形式。挙動は `node --test` と `opa test` で見る。
  - `pnpm run check` は置かない。
  - `PUBLIC_` 以外の環境変数をコミットしない（hook で検知）。
- 結果: 型緑の偽シグナルを置かない。
- 関連: [[0016-definition-of-done]] [[0039]]

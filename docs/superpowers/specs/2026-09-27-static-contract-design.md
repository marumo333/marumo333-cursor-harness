# 正解は型と振る舞いの契約

日付: 2026-09-27。決定は ADR 0051。Feature F-0016 は proposed。適用の被覆は F-0001。

## 正解

契約は2つだけである。

1. 型。実装の関数が契約の型に代入できる。判定は `tsc --noEmit`。
2. 振る舞い。契約に書いた引数で呼び、戻り値か例外が一致する。判定は実行。

LLM が差分を読んで「問題が無い」と言うことは、正解ではない。

## 置き場所

- `contracts/<name>.contract.ts` が型、代入チェック、振る舞いの一覧を持つ。
- `scripts/lib/<name>.ts` が実装で、契約の型を注釈に持つ。
- `node scripts/contract-check.mjs` が両方を見る。feature-gate が成功する前にこれを通す。

最初の契約は `clamp`。範囲の両端と、下限が上限を超えたときの例外を書く。

## レビュー

契約が緑の振る舞いについて、レビューは差し戻さない。

レビューが差し戻せるのは、型と振る舞いでは赤にならないもののうち、席・正本・ゲート・秘密に当たり、見た差分で再現できるものだけ。

新しい周のレビュー起動は 4 まで（初回 3 体と再確認 1 回）。既に記録された周は、その回数を超えて増やせない。超えたら `node scripts/review-cap-check.mjs` が失敗する。

## 依存

型検査だけに `typescript` を devDependency としてピンする。振る舞いの実行は Node の型除去で契約ファイルを読む。判定ロジックにモデルは使わない。
